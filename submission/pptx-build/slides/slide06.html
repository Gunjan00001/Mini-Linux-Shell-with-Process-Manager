Module Breakdown

9 small components, one clear job each

  • Shell loop: shell/, prompt, select driven line reader
  • Parser: parser/, quotes, |, <, >, >>, & → ParsedLine
  • Executor: executor/, builtin dispatch, fork/exec pipelines
  • Job table: process/, job ids, states, reaping, SIGHUP at exit
  • Terminal: process/, shell pgid, tcsetpgrp handoff
  • IPC: ipc/, open/dup2/close for redirection
  • Signals: signals/, sigaction, self pipe, child reset
  • Monitor: monitor/, /proc parsing, monitor/ps/pinfo
  • History: history/, in memory command list

Data contract: ParsedLine { stages, background, ok } is the only thing passed parser → executor.
