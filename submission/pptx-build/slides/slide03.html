Problem Statement & Scope

What is implemented, and what is deliberately not

In scope

  • Interactive Linux shell in C++17 using POSIX system calls directly
  • Pipelines, I/O redirection, background jobs, full job control
  • Signal safe child reaping; the shell survives Ctrl+C
  • Monitoring the whole system and individual processes from /proc

Deliberately out of scope

  • No globbing (*.txt), variable expansion, ; / && / ||
  • No tab completion or line editing
  • Builtins cannot appear inside a pipeline
  • Linux only, because POSIX semantics are the point of the project
