Introduction & Objective

Why build a shell?

What is a shell?

The program between the user and the kernel: it reads a command line, and asks the OS to run it.

Most shells hide the machinery. We show it.

Objective

  • Implement the core OS mechanisms from scratch: fork, execvp, waitpid, pipes, dup2 redirection
  • Real terminal job control: process groups, tcsetpgrp, Ctrl+C / Ctrl+Z, fg/bg
  • Safe SIGCHLD reaping through a self pipe
  • A process manager reading the Linux /proc filesystem
