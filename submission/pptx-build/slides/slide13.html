Limitations & Future Scope

Known ceilings, honest list

Limitations

  • No globbing, variable expansion, ; / && / ||
  • Builtins: no redirection, cannot join a pipeline
  • No stderr redirection; no tab completion or line editing
  • Background output can interleave with the prompt

Future scope

  • Line editing with GNU Readline (arrows, tab completion)
  • Environment expansion, globbing, 2> stderr redirection
  • Run builtins in subshells so they work inside pipelines
  • Script files and a noninteractive mode with ; && ||
